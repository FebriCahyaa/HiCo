# Supported LineageOS devices (non-Xiaomi)

Generated by [`tools/lineage_devices.py`](../tools/lineage_devices.py) from
LineageOS device trees (`LineageOS/android_device_<vendor>_<codename>`) and
their vendor blobs on [TheMuppets](https://github.com/TheMuppets). Only the
thermal-related paths are sparse-cloned so the whole scan of ~20 devices
finishes in about two minutes and pulls a few kilobytes per phone.

Files live in `devices/<vendor>/<codename>/thermal/`. Each device has:

- `<codename>.prop` — a profile line HiCo reads at build time (source URL
  carries the device-tree HEAD commit SHA so incremental runs can skip
  unchanged devices with `--only-changed`);
- `thermal/*.conf` or `thermal/*.json` — the stock thermal files exactly as
  the ROM ships them, one file per scene;
- `thermal/index.tsv` — SHA-256, size, format and trip points so a reviewer
  can tell what changed without diffing binaries.

The Xiaomi record set stays under
[`docs/DEVICES.md`](DEVICES.md) — it comes from a different source
(dumps.tadiphone.dev firmware dumps) and covers 190+ Xiaomi / Redmi / POCO
models the LineageOS scanner does not touch.

## What each format means for HiCo

| Format | Files | Vendors seen | Tunable by HiCo? |
|---|---|---|---|
| Android Thermal HAL 2.0 JSON | `thermal_info_config*.json` | Pixel, Motorola (newer), Nothing | ✅ `haljson::tune` |
| Qualcomm `thermal-engine.conf` (INI) | `thermal-engine.conf`, `thermal-*.conf` | Fairphone, Motorola (older), Nothing | ✅ `tune_engine` |
| Xiaomi `mi_thermald` (plain / encrypted) | `thermal-*.conf` (mostly encrypted on HyperOS) | Xiaomi / Redmi / POCO | ✅ `mithermald::tune` + `micrypt::decrypt/encrypt` |

## Devices in this repository

Devices are added a scan at a time (curated codenames until the workflow
runs across everything on schedule). The manual seed captured on the day
of the first ingest scans a Pixel line spanning 4a — Pixel 9 Pro Fold and a
few OEMs known to publish full vendor blobs on TheMuppets.

Snapshot at seed:

- **google (Pixel)** — akita, bluejay, caiman, cheetah, felix, husky,
  komodo, lynx, oriole, panther, raven, shiba, tangorpro, tokay
- **fairphone** — FP3, FP4, FP5
- **motorola** — bronco, devon
- **nothing** — Spacewar (Phone (1))
- **xiaomi** (extra beyond the tadiphone set) — cupid

Vendors known to keep thermal in DT rather than user-space (Samsung Exynos)
or to publish vendor blobs at a fork rather than TheMuppets (some OnePlus,
Realme, Oppo, Sony, Asus) are recorded in
[`THERMAL-COVERAGE.md`](THERMAL-COVERAGE.md) as gaps to address one vendor
at a time.

## How to add more devices

```sh
# One at a time (fastest):
python3 tools/lineage_devices.py --codenames tokay,husky,devon

# All LineageOS build targets (long run):
python3 tools/lineage_devices.py

# Only re-scan devices whose LineageOS device tree moved since last time:
python3 tools/lineage_devices.py --only-changed
```

Every scan is idempotent: unchanged phones do not re-write their `.prop`
file, so `git status` after a run tells you exactly which phones moved.
