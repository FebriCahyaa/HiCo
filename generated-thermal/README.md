# Generated HiCo Thermal

This directory contains candidate thermal configurations generated by the host `hicod` implementation from the original files in `thermal-data/`.

- `candidate/` keeps the candidate in the same format as the source, including encrypted Xiaomi `mi_thermald` data when applicable.
- `review/` keeps a readable representation where HiCo can produce one, for human inspection.
- `generation.json` records the exact source, policy, file-level status and verification result.

Source files are never modified. Every generated file is checked with `hicod thermal check` before being marked `generated`.
